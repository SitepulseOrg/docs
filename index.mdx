SitePulse helps teams monitor website health across uptime, SSL, DNS, broken links, and performance. Each site can be checked manually, monitored automatically, and the team receives notifications when problems are detected.

## What SitePulse does

SitePulse provides continuous monitoring for critical website health metrics:

- **Uptime monitoring** - Track HTTP status codes, response times, and redirects
- **SSL certificate tracking** - Monitor certificate validity and expiration dates
- **DNS record verification** - Ensure DNS records are properly configured
- **Broken link detection** - Identify and fix failing links across your site
- **Performance monitoring** - Measure Core Web Vitals and Lighthouse scores
